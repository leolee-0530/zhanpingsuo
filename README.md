# 展评所 MVP

一个以真实观展、结构化评价和组团看展为核心的展览发现网站原型。

## 本地运行

```bash
python3 -m http.server 4173 --directory artifacts/zhanpingsuo
```

打开 `http://127.0.0.1:4173`。

## 数据说明

- 展览名称、场馆、展期和简介来自页面中标注的官方来源，核验日期为 2026-10-06。
- 当前收录 16 个真实展览，封面均采用场馆或主办方公开发布的主视觉或展览图片；无法可靠核验图片来源的条目暂不展示。
- 展览图片仅用于产品原型展示，版权归原权利人所有。
- 站内评分、短评、活动与参与人数均为产品演示数据。
- 用户的“想看”“看过”“收藏”、展评和组团报名存储在浏览器 `localStorage`。
